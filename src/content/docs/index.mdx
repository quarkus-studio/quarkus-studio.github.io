## Quick Installation

Get Quarkus Studio up and running in your favorite IDE in seconds:

<Tabs>
  <TabItem label="VS Code CLI">
```bash
code --install-extension maratib.quarkus-studio
```
  </TabItem>
  <TabItem label="VSCodium CLI">
```bash
codium --install-extension maratib.quarkus-studio
```
  </TabItem>
  <TabItem label="Open VSX Registry">
Visit the official [Open VSX Extension Page](https://open-vsx.org/extension/maratib/quarkus-studio) to download the `.vsix` package or install it in Gitpod, Eclipse Theia, and Eclipse Che.
  </TabItem>
</Tabs>
